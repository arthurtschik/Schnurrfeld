Was die App speichert

Spielstand, Einstellungen und der Zustand deines Kätzchens liegen nur lokal auf dem Gerät. Die App legt kein Konto an, sendet keine Spielstände ab und nutzt keine Analyse- oder Werbedienste und keine fremden Software-Bausteine mit Netzwerkzugriff.

Wenn du die Android-Datensicherung aktiviert hast, kann Android deinen Spielstand in dein Google-Konto sichern. Das geschieht über Android und Google, nicht über die App.

Verbindung zu GitHub (Update-Suche)

Beim Start der App und wenn du „Nach Updates suchen“ antippst, fragt die App bei GitHub (api.github.com, GitHub Inc., USA) nach der neuesten Version. Dabei erhält GitHub wie bei jedem Aufruf einer Webseite deine IP-Adresse und den Namen der App („Schnurrfeld-App“). Sonst wird nichts gesendet. Rechtsgrundlage ist unser berechtigtes Interesse, dich mit Sicherheitskorrekturen zu versorgen (Art. 6 Abs. 1 lit. f DSGVO).

Ein Update lädt die App nur von GitHub aus dem Projekt Schnurrfeld per HTTPS herunter. Vor der Installation prüft sie, dass die Datei dieselbe App, eine höhere Version und denselben Signaturschlüssel hat. Installiert wird erst, wenn du es in Android bestätigst.

Die automatische Suche kannst du unter Einstellungen › App abschalten.

Empfänger, USA und Speicherdauer

Empfänger ist nur GitHub (GitHub Inc., USA, Teil der Microsoft Corporation). Die Übermittlung in die USA stützt sich auf den EU-US Data Privacy Framework beziehungsweise Standardvertragsklauseln. Ich selbst speichere keine Daten aus der Update-Suche. Wie lange GitHub Zugriffsdaten speichert, regelt GitHub in der eigenen Datenschutzerklärung.

Pflicht und automatische Entscheidungen

Du musst keine Daten angeben. Ohne Update-Suche funktioniert die App vollständig, du bekommst dann nur keine Hinweise auf neue Versionen. Eine automatisierte Entscheidungsfindung oder ein Profiling findet nicht statt.

Berechtigungen

  • Internet: nur für die Update-Suche (siehe oben)
  • Vibration: für das Feedback beim Spielen, abschaltbar in den Einstellungen
  • Apps installieren: damit die App ein heruntergeladenes Update nach deiner Bestätigung installieren kann

Die App braucht kein Mikrofon, keinen Standort, keine Kontakte und keinen Speicherzugriff.
